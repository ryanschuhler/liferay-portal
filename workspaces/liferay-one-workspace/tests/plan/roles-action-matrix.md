# Roles — Action Matrix (Working Doc)

Source of truth for per-role grant/deny test expectations. Each plan item in
[`roles-permissions.md`](./roles-permissions.md) (`ROLE-*`) is covered when a test
authenticates as a user holding the role and asserts it grants the **Allows** actions
and denies others. The **Allows** column is seeded `TBD` — fill it from the product
permission spec, then implement the test referencing the plan ID.

This is a working document, not a plan table; `check-plan`/`check-coverage` ignore it.
